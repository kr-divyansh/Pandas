# 🐼 Pandas

A repository dedicated to learning and practicing **Pandas**, a powerful Python library used for data manipulation, analysis, and preprocessing.

## 📌 About

This repository contains my Pandas learning journey, including practical examples, important functions, data cleaning techniques, and hands-on exercises using datasets.

## 📚 Topics Covered

- Introduction to Pandas
- Series and DataFrames
- Reading and writing CSV files
- Data selection and indexing (`loc`, `iloc`)
- Handling missing values
- Removing duplicates
- Data filtering and sorting
- GroupBy and aggregation
- Merging, joining, and concatenating DataFrames
- Data cleaning and preprocessing
- Basic Exploratory Data Analysis (EDA)

## 🛠️ Technologies Used

- Python
- Pandas
- Jupyter Notebook
- NumPy

## ⚙️ Installation

Install Pandas using pip:

```bash
pip install pandas
```

For Jupyter Notebook:

```bash
pip install notebook
```

## 🚀 Getting Started

1. Clone this repository.
2. Open the notebooks in Jupyter Notebook.
3. Run the code examples and practice the concepts.
4. Experiment with different datasets to improve your data analysis skills.

## 🎯 Goal

To build a strong foundation in data manipulation, data cleaning, and exploratory data analysis for **Machine Learning and Data Science**.
